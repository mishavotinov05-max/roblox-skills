# Wall Breaking Simulator — инструкция

Файл игры: **`WallBreaker.rbxlx`**. Это готовое место (place) для Roblox Studio. Внутри всё уже есть: карта из обычных деталей, интерфейс и все скрипты. Карта существует в Studio **до запуска игры**: её можно двигать, масштабировать и перекрашивать обычными инструментами.

---

## 1. Как открыть

1. Установите **Roblox Studio**: <https://create.roblox.com> → «Start Creating».
2. Скачайте `WallBreaker.rbxlx` из репозитория. На GitHub откройте файл и нажмите **Download raw file**.
3. Откройте его двойным щелчком или в Studio через **File → Open from File…**.
4. Включите окна **View → Explorer**, **View → Properties** и **View → Output**. В окне Output видны ошибки, если они появятся.

### Первым делом: опубликуйте игру и включите сохранения

Без этого шага прогресс игроков не будет сохраняться:

1. **File → Publish to Roblox** → «Create new game» → придумайте название.
2. **Home → Game Settings → Security** → включите **Enable Studio Access to API Services** → Save.

## 2. Как протестировать

Нажмите **Play** (F5). Что проверить по порядку:

| Шаг | Что сделать | Что должно произойти |
|---|---|---|
| 1 | Вы появляетесь на фиолетовой площадке, кирка уже в руке | Слева кнопки 2×2, ниже «Сила / Удача / Победы» |
| 2 | Подойдите к левой зоне и спрыгните в яму **«Землянка»** (первая у входа в уровни) | — |
| 3 | Кликайте мышкой (на телефоне — тап) | «Сила» растёт, появляются цифры «+1 силы» |
| 4 | Наберите ~10 силы, выпрыгните (пробел) и идите в арку **«УРОВНИ»** | Сверху появится панель уровня |
| 5 | Бейте стену «Сено» | Слои по очереди исчезают, летят обломки, иногда выпадает руда |
| 6 | После 10-го слоя идите в нишу справа, встаньте на **жёлтую** площадку | «+1 победа» |
| 7 | Встаньте на **зелёную** площадку | Телепорт в лобби |
| 8 | Магазин кирок справа: встаньте на площадку перед киркой и нажмите **E** | Кирка куплена и в руках |
| 9 | Торговец в углу: **E** | Руды проданы за победы |
| 10 | Яйца у южной стены: **E** (нужно 10 побед) | Выпал питомец, он летает за вами |
| 11 | Кнопки: Колесо, Награды, Задания, Достижения, Настройки, Перерождение | Открываются окна, кнопки работают |

**Быстрый тест без долгого фарма:** откройте `ReplicatedStorage → Config → GameSettings` и поставьте `StudioTestWins = 1000`. Новый игрок в Studio получит 1000 побед. Перед публикацией верните 0.

> Если что-то не работает — скопируйте красный текст из окна **Output** и пришлите мне.

## 3. Где что лежит (Explorer)

```
Workspace
└─ Map
   ├─ Hub                    ← лобби
   │  ├─ Floor, Walls, Decor ← пол, стены, фонари
   │  ├─ SpawnLocation       ← точка появления
   │  ├─ LevelEntrance       ← арка «УРОВНИ»
   │  ├─ PickaxeShop         ← магазин кирок (Steps, Slots/Slot_01…Slot_12)
   │  ├─ Pits                ← ямы Pit_01…Pit_12
   │  ├─ Eggs                ← Egg_common, Egg_rare, Egg_epic
   │  └─ OreTrader           ← торговец рудами
   ├─ Levels                 ← Level_01…Level_10
   │  └─ Level_01
   │     ├─ Wall             ← слои Layer_01…Layer_10
   │     ├─ Sign             ← табличка перед уровнем
   │     ├─ RewardPad        ← жёлтая площадка награды
   │     ├─ LobbyPad         ← зелёная площадка «В лобби»
   │     ├─ MerchantSpot     ← место редкого торговца (невидимое)
   │     ├─ Zone             ← невидимая зона уровня
   │     └─ Structure        ← пол, стены, балки, фонари
   └─ Ground                 ← трава и декоративные блоки вокруг
ReplicatedStorage
├─ Config                    ← ВСЕ ЦИФРЫ ИГРЫ (см. раздел 4)
├─ Shared                    ← общие формулы
└─ PetModels                 ← сюда можно положить свои модели питомцев
ServerScriptService
├─ Main                      ← запуск сервера
└─ Services                  ← системы: сохранение, удары, стены, магазины…
ServerStorage
├─ PickaxeModels             ← сюда можно положить свои модели кирок
└─ RareMerchantTemplate      ← внешний вид редкого торговца
StarterGui
└─ MainHud                   ← весь интерфейс
StarterPlayer → StarterPlayerScripts → ClientMain → Controllers ← скрипты интерфейса
```

**Главное правило:** скрипты находят объекты **по имени**. Двигать, растягивать, перекрашивать и менять материал можно как угодно. Переименовывать объекты с именами вроде `Layer_03`, `Pit_05`, `Slot_07`, `BuyPad`, `RewardPad`, `Zone`, `TrainZone`, `LockBarrier` нельзя.

## 4. Конфиги: все цифры в одном месте

Двойной щелчок по модулю в `ReplicatedStorage → Config` открывает его. Каждая строка подписана по-русски.

| Модуль | Что там |
|---|---|
| `GameSettings` | Скорость ударов, автосохранение, редкий торговец, тестовые победы |
| `LevelConfig` | Уровни: название, прочность (`BaseHP`), награда (`WinsReward`), рост прочности слоёв |
| `PickaxeConfig` | Кирки: цена, сила (`Power`), цвет |
| `PitConfig` | Ямы: сколько перерождений нужно, сколько силы за удар |
| `PetConfig` | Питомцы (бонус к силе) и яйца (цена, шансы) |
| `OreConfig` | Руды: шанс выпадения и цена у торговца |
| `AuraConfig` | Ауры: цена и множитель |
| `RebirthConfig` | Цена перерождения и бонус |
| `ShopConfig` | Удача и платные покупки (Robux) |
| `WheelConfig` | Колесо фортуны: призы и шансы |
| `RewardsConfig` | Ежедневные награды, задания, достижения |
| `IconConfig` | Картинки кнопок |

## 5. Частые задачи

### Передвинуть стену, яму, магазин, яйцо
1. Выберите объект в Explorer: модель целиком, например `Pit_03`, или отдельную деталь.
2. Инструменты **Move / Scale / Rotate** на вкладке Home → тяните стрелки.
3. Цвет и материал меняются в окне Properties (`Color`, `Material`).

### Изменить цену кирки
`Config → PickaxeConfig` → найдите строку, например `Name = "Золотая"` → поменяйте `Price = 100` на нужное число. Надпись над площадкой обновится сама при запуске.

### Изменить прочность стены или награду
`Config → LevelConfig` → у нужного уровня поменяйте `BaseHP` (прочность) или `WinsReward` (сколько побед). Число слоёв задаёт `LayersPerLevel`.

### Добавить уровень 11
1. В `LevelConfig` допишите строку: `{ Id = 11, Name = "Кристалл", BaseHP = 60000000, WinsReward = 1 },`
2. В Explorer: `Map → Levels → Level_10` → правый клик → **Duplicate** → переименуйте копию в `Level_11`.
3. Выделите `Level_11` и сдвиньте его на **72 стада дальше** по прямой (ось Z, в сторону минуса). Удобно через Move: шаг сетки 1 стад.
4. В `Level_10 → Structure` удалите `EndWall` (стену-тупик), чтобы открыть проход дальше.
5. Перекрасьте слои `Level_11 → Wall → Layer_01…Layer_10` (Color/Material).

### Добавить яйцо
1. В `PetConfig → Eggs` допишите: `{ Id = "mega", Name = "Мега-яйцо", Price = 2000, Pets = { { "dragon", 60 }, { "phoenix", 40 } } },`
2. Скопируйте модель `Map → Hub → Eggs → Egg_epic`, назовите копию `Egg_mega`, поставьте рядом.
3. Новые питомцы добавляются в `PetConfig → Pets`.

### Открыть новую яму
В `PitConfig` допишите строку, например `{ Name = "Изумрудная", RequiredRebirths = 60, Power = 300 },`. Она займёт следующее свободное место (`Pit_07`). Цвет ямы меняется у деталей внутри `Pit_07`.

### Поменять кнопки интерфейса
`StarterGui → MainHud`:
- `LeftMenu` — кнопки 2×2. Их расставляет `UIGridLayout`. Размер ячеек задаёт `CellSize`, отступы — `CellPadding`. Чтобы двигать кнопки свободно, удалите `UIGridLayout`.
- Цвет кнопки — `BackgroundColor3`, подпись — `Label → Text`.
- `Stats` — сила, удача, победы. `TopRight` — колесо и 4 кнопки справа.
- `Panels` — окна. В каждом окне есть скрытая карточка `Template`: перекрасьте её, и так будут выглядеть все карточки в списке.

Подсказка: чтобы увидеть окно в Studio, выберите его (например `Panels → ShopPanel`) и включите `Visible`. Перед сохранением выключите обратно.

### Поставить нарисованные иконки
1. **View → Asset Manager → Bulk Import** → выберите PNG из папки `art/icons`.
2. Правый клик по картинке → **Copy Asset ID**.
3. Вставьте ID в `Config → IconConfig` вместо `rbxassetid://0` (рядом с каждой строкой подписано, какой файл туда нужен).

Пока ID не вставлены, на кнопках показываются эмодзи-заглушки. Когда ID вставлены, символы на кнопках анимируются: магазин качается, лапка прыгает, огонь пульсирует, стрелки крутятся, колесо вращается.

### Заменить модель объекта
- **Кирка в руках:** положите свой Tool в `ServerStorage → PickaxeModels` и назовите как Id кирки (`gold`, `diamond`…). Внутри должна быть деталь `Handle`.
- **Питомец:** положите Model в `ReplicatedStorage → PetModels` с именем как Id питомца (`dog`, `dragon`…).
- **Торговец, яйцо, витрина кирки:** можно удалить детали внутри модели и вставить свои. Оставьте деталь с **ProximityPrompt** (у торговца это `Counter`, у яйца — `Pedestal`, у кирки — `BuyPad`) или перенесите ProximityPrompt в новую деталь внутри той же модели.
- **Модели из Creator Store:** Toolbox → вставьте модель → перетащите в нужную папку. Удалите из чужих моделей лишние скрипты, если не уверены, что они безопасны.

### Покупки за Robux
1. Опубликуйте игру. Затем create.roblox.com → ваша игра → **Monetization → Passes** (геймпассы) или **Developer Products** (товары).
2. Создайте товар и скопируйте его **ID**.
3. Вставьте ID в `Config → ShopConfig` вместо `Id = 0`.

Пока стоит 0, кнопка покупки пишет «Покупка ещё не настроена».

## 6. Как опубликовать

1. **File → Publish to Roblox**.
2. **Home → Game Settings**: название, описание, иконка, **Permissions → Public**.
3. Проверьте игру по ссылке на сайте Roblox, с телефона тоже.

## 7. Что уже работает

- Удары киркой (клик/тап) с проверками на сервере.
- Ямы прокачки силы: 6 видов, открываются по перерождениям, плюс 6 свободных мест.
- 10 уровней по 10 слоёв, свои у каждого игрока.
- Награда +1 (×3 с геймпассом) один раз за прохождение и возврат в лобби.
- Руды: 5 видов с шансами и бонусом удачи. Торговец в лобби и редкий торговец на уровнях (платит ×2).
- Магазин: 12 кирок, улучшение удачи, геймпассы и товары за Robux.
- Яйца и питомцы: открытие, надеть/снять, «надеть лучших», удаление. Питомцы летают за игроком.
- Ауры: покупка, надевание, эффект свечения.
- Перерождение: сброс, бонус к силе, новые ямы.
- Колесо фортуны: бесплатное вращение раз в 15 минут и купленные вращения.
- Ежедневные награды (7 дней), 3 ежедневных задания, 8 достижений.
- Настройки: автоклик (геймпасс), показ питомцев, кнопка «В лобби».
- Сохранение всего прогресса в DataStore с защитой от двойной выдачи покупок.
- Интерфейс подстраивается под размер экрана, работает на телефоне.

**Пока не сделано:** вагонетки (вы убрали их кнопку; можно добавить позже), звуки и музыка.
