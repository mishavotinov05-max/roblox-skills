# Туториал: как менять тексты и ставить иконки в Roblox Studio

Перед началом откройте окна **View → Explorer**, **View → Properties** и **View → Output**.

> **Главное правило:** меняйте только когда игра **остановлена**. Всё, что поменяли после ▶ Play, пропадает после ■ Stop.
> После изменений сохраняйте: **File → Save to File** (Ctrl+S) или **File → Publish to Roblox**.

---

## Часть 1. Тексты

В игре есть 2 вида надписей.

### А) Обычные надписи — меняются прямо в Studio

Это подписи кнопок, вывески и названия окон.

1. В **Explorer** раскройте нужный объект (стрелочка ▸ слева от имени).
2. Найдите **TextLabel** или **TextButton** и щёлкните по нему.
3. В **Properties** найдите строку **Text** и впишите новый текст.
   - Новая строка внутри текста: нажмите `Shift+Enter`.
   - Цвет текста — свойство **TextColor3**, обводка — объект **UIStroke** внутри надписи.

Где что лежит:

| Что поменять | Путь в Explorer |
|---|---|
| Подпись «Магазин» на кнопке слева | `StarterGui → MainHud → LeftMenu → ShopButton → Label` |
| «Питомцы», «Ауры», «Перерождения» | там же: `PetsButton → Label`, `AurasButton → Label`, `RebirthButton → Label` |
| «Настройки», «Задания», «Колесо», «Награды» | `StarterGui → MainHud → TopRight → (кнопка) → Label` |
| «Победы», «Сила», «Удача» на карточках | `StarterGui → MainHud → Stats → WinsRow → Title` (и `StrengthRow`, `LuckRow`, `RebirthRow`) |
| «Мощный удар» | `StarterGui → MainHud → PowerPanel → PowerStrikeButton → Text` |
| Заголовок окна (например «Магазин») | `StarterGui → MainHud → Panels → ShopPanel → Title` |
| Вывеска «УРОВНИ» над аркой | `Workspace → Map → Hub → LevelEntrance → Sign → SignGui → Board → Title` |
| Вывеска «КИРКИ» | `Workspace → Map → Hub → PickaxeShop → Sign → SignGui → Board → Title` |

**Как быстро найти надпись:** в Explorer есть строка поиска сверху (Filter workspace). Введите имя, например `ShopButton`, и Studio покажет этот объект.

**Как увидеть окно (панель) в редакторе:** выберите, например, `MainHud → Panels → ShopPanel` и поставьте галочку **Visible**. Перед сохранением снимите её обратно.

### Б) Надписи, которые пишет скрипт — меняются в конфигах

Эти надписи при запуске игры берутся из настроек. Если поменять их на табличке, после ▶ Play они вернутся. Меняйте их в конфиге: `ReplicatedStorage → Config`, двойной щелчок по модулю открывает его как текст.

| Что поменять | Где менять |
|---|---|
| Названия ям и «Перерождения: N» | `PitConfig` → `Name`, `RequiredRebirths` |
| Названия и цены кирок на витрине | `PickaxeConfig` → `Name`, `Price`, `Power`, `Rarity` |
| Названия яиц, цены, питомцы, шансы | `PetConfig` → `Eggs` и `Pets` |
| Таблички уровней («Уровень 1 · Сено») | `LevelConfig` → `Name`, `WinsReward` |
| Призы колеса | `WheelConfig` → `Text` |
| Задания и достижения | `RewardsConfig` → `Text` |
| Названия товаров за Robux | `ShopConfig` → `Name` |

Пример — переименовать яму:
1. Двойной щелчок по `ReplicatedStorage → Config → PitConfig`.
2. Найдите строку `{ Name = "Обычная яма", RequiredRebirths = 0, Power = 2 },`.
3. Замените текст в кавычках, например на `"Стартовая яма"`. Кавычки и запятые не удаляйте.
4. Ctrl+S, затем ▶ Play — новое название появится на табличке.

Если после правки конфига в Output появилась красная ошибка, скорее всего пропала кавычка или запятая. Нажмите Ctrl+Z.

## Часть 2. Мои иконки

Иконки лежат в репозитории в папке `games/wall-breaker/art/icons` (PNG-файлы). Roblox показывает только картинки, загруженные в ваш аккаунт, поэтому их нужно загрузить один раз.

### Шаг 1. Скачайте иконки на компьютер

На GitHub откройте папку `games/wall-breaker/art/icons` и скачайте нужные PNG (кнопка **Download raw file** у каждого файла). Или скачайте весь репозиторий: зелёная кнопка **Code → Download ZIP**, затем распакуйте.

### Шаг 2. Загрузите их в Roblox

1. Игра должна быть **опубликована** (File → Publish to Roblox).
2. **View → Asset Manager** (Менеджер ресурсов).
3. Кнопка **Bulk Import** (значок со стрелкой вверх) → выберите PNG-файлы → Открыть.
4. Подождите 1–2 минуты: Roblox проверяет картинки. Они появятся в папке **Images**.

### Шаг 3. Скопируйте ID картинки

В Asset Manager: правый щелчок по картинке → **Copy Asset ID**. Скопируется число вида `rbxassetid://1234567890`.

### Шаг 4. Вставьте ID в конфиг

Откройте `ReplicatedStorage → Config → IconConfig` и замените `rbxassetid://0` на скопированный ID в нужной строке:

```lua
ShopTile = "rbxassetid://1234567890", -- layer_tile_shop.png
```

Какую картинку куда вставлять (рядом с каждой строкой в IconConfig тоже подписано):

| Строка в IconConfig | Файл |
|---|---|
| `ShopTile`, `ShopSymbol` | `layer_tile_shop.png`, `layer_sym_shop.png` (корзина) |
| `PetsTile`, `PetsSymbol` | `layer_tile_pets.png`, `layer_sym_pets.png` |
| `AurasTile`, `AurasSymbol` | `layer_tile_auras.png`, `layer_sym_auras.png` |
| `RebirthTile`, `RebirthSymbol` | `layer_tile_rebirth.png`, `layer_sym_rebirth.png` |
| `WheelBase`, `WheelDisc`, `WheelTop` | `layer_wheel_base.png`, `layer_wheel_disc.png`, `layer_wheel_top.png` |
| `Settings`, `Quests`, `Rewards` | `bar_settings.png`, `bar_daily.png` (свиток), `bar_rewards.png` |
| `Wins`, `Strength`, `Luck` | `stat_wins.png`, `stat_strength.png`, `stat_luck.png` |
| `LevelSword`, `PowerSword` | `icon_sword.png`, `icon_sword_dark.png` |
| `PassWinsX3` … `PassAutoClick` | `pass_wins_x3.png`, `pass_strength_x2.png`, `pass_luck_x2.png`, `pass_auto_click.png` |

### Шаг 5. Проверьте

Ctrl+S → ▶ Play. Эмодзи на кнопках заменятся иконками, а символы начнут двигаться: корзина качается, лапка прыгает, огонь пульсирует, стрелки крутятся, колесо вращается.

**Если иконка не появилась:**
- проверьте, что ID вставлен внутри кавычек и начинается с `rbxassetid://`;
- подождите пару минут: только что загруженная картинка может быть ещё на проверке у Roblox;
- откройте Output — если там ошибка про IconConfig, значит пропала кавычка или запятая.

### Свою картинку можно поставить так же

Нарисовали свою иконку — загрузите её через Bulk Import и вставьте её ID в нужную строку IconConfig вместо моей.

## Часть 3. Текстуры карты (кирпич, трава, стены уровней)

Работает так же, как иконки:
1. Загрузите PNG из `games/wall-breaker/art/textures` через **Asset Manager → Bulk Import**.
2. Вставьте их ID в `ReplicatedStorage → Config → TextureConfig`. Рядом с каждой строкой подписано имя файла.
3. ▶ Play — текстуры появятся на стенах, полу, ямах и слоях стен.

Чтобы текстуры было видно и в редакторе, без Play: **View → Command Bar**, вставьте строку и нажмите Enter:

```lua
require(game.ReplicatedStorage.Shared.TextureApplier).Apply()
```

## Часть 4. Размер блоков интерфейса

Карточки слева внизу и нижний блок (сила, уровень, опыт) меняют размер одним числом:
- `StarterGui → MainHud → Stats → Size` → свойство **Scale** (сейчас 0.7);
- `StarterGui → MainHud → PowerPanel → Size` → свойство **Scale**.

Сейчас стоит `0.6`. `1` — исходный размер, `0.5` — в 2 раза меньше.

## Часть 5. Как менять графику

| Что | Где в Explorer | Какие свойства |
|---|---|---|
| Освещение, время суток, тени | `Lighting` | `ClockTime` (время), `Brightness`, `ShadowSoftness`, `Technology` (ShadowMap — быстрее, Future — красивее) |
| Свечение, сочность цветов, лучи, дымка | `Lighting → Bloom`, `ColorCorrection`, `SunRays`, `Atmosphere` | `Intensity`, `Saturation`, `Density` и т.д. |
| Небо | `Lighting → Sky` | свои картинки неба в полях `SkyboxBk/Dn/Ft/Lf/Rt/Up` |
| Цвет пола зала | `Workspace → Map → Hub → Floor` (выделите все детали) | `Color` |
| Дорожка и бортики | `Workspace → Map → Hub → Decor → Path_Center`, `PathTrim_L/R`, `Border*` | `Color`, `Material` |
| Холмы вокруг зала | `Workspace → Map → Hub → Walls → Cliff_*`, `Trim_*`, `GrassCliff_*` | `Color`, `Material`, размер инструментом Scale |
| Ёлки | `Workspace → Map → Hub → Trees` | `Color` листьев и ствола |
| Стены уровней (слои) | `Workspace → Map → Levels → Level_01 → Wall → Layer_01…10` | `Color`, `Material`; рисунок — `Config → TextureConfig` |
| Витрины кирок | `Workspace → Map → Hub → PickaxeShop → Slots → Slot_XX` | подставка `Pedestal`, подсветка `Glow`, сама кирка `Display` |
| Кирка в руках | цвет — `Config → PickaxeConfig` (`Color`, `HandleColor`); своя модель — `ServerStorage → PickaxeModels` | |
| Ямы | `Workspace → Map → Hub → Pits → Pit_XX` | `PitFloor`, `Wall*`, `Rim`, `Props` (кристаллы) |
| Яйца | `Workspace → Map → Hub → Eggs → Egg_XX` | `Egg`, `Pedestal`, `Ring`, украшения |
| Питомцы | цвет — `Config → PetConfig`; своя модель — `ReplicatedStorage → PetModels` (имя = Id питомца) | |
| Режимы графики (низкая/средняя/высокая) | что включает каждый режим — `StarterPlayerScripts → ClientMain → Controllers → Graphics` (таблица `MODES`) | игрок переключает в «Настройки → Графика» |

## Часть 7. «Пупырышки» на стенах

Холмы вокруг зала (`Workspace → Map → Hub → Walls → Cliff_*`) используют классические поверхности Roblox со «стадами»: свойства `TopSurface`, `FrontSurface` и т.д. = **Studs**. Убрать их можно, поставив **Smooth**.

## Часть 8. Кирки-картинки (точь-в-точь как нарисованы)

1. Подготовьте 16 PNG без фона — по одной кирке на картинку, рукоять снизу-слева, головка сверху-справа.
2. Загрузите их (Asset Manager → Bulk Import) и вставьте ID в `Config → PickaxeConfig` → поле `Image` у каждой кирки.
3. ▶ Play: кирка в руке, на спине и на витрине магазина станет этой картинкой.

Подстройка: `GameSettings → PickaxeImageSize` (размер в руке), `PickaxeImageMirror` (если головка смотрит не туда), `PickaxeGripTilt` (наклон).
Пока `Image = "rbxassetid://0"`, показывается кирка, собранная из деталей.
