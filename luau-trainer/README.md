# Тропа Luau

Тренажёр языка Luau (скрипты Roblox) в стиле Duolingo, на русском.

- 12 разделов, 36 уроков, 216 заданий (выбор ответа, вставка пропуска, сборка кода)
- Тест в конце каждого раздела (8/10 для зачёта), досрочная сдача, итоговый экзамен на 30 вопросов
- Сердца, XP, серия дней, работа над ошибками, справочник теории
- Практические задания для Roblox Studio к каждому разделу
- Калькулятор сроков обучения при 30–60 минутах в день

Открой `index.html` в браузере. Прогресс хранится в localStorage.
`app.html` — та же страница без обёртки `<html>` (для публикации как Artifact).
