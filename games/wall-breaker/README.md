# Wall Breaking Simulator

**Игра:** `WallBreaker.rbxlx` — откройте в Roblox Studio. Подробная инструкция — **[ИНСТРУКЦИЯ.md](ИНСТРУКЦИЯ.md)**.

Также здесь лежат **иконки** для интерфейса и **3D-превью** (макет) карты.

## Что здесь лежит

```
WallBreaker.rbxlx     ← файл игры для Roblox Studio (собирается из src/ скриптом tools/build_place.py)
ИНСТРУКЦИЯ.md         ← как открыть, тестировать, менять и публиковать
src/                  ← исходники скриптов (Luau): конфиги, сервер, клиент
art/
  icons/              ← 45 иконок PNG 512×512 с прозрачным фоном (готовы к загрузке в Roblox)
  icons_sheet.png     ← все иконки на одном листе
  preview/            ← скриншоты 3D-превью и видео wall_breaker_preview.mp4
tools/                ← исходники, из которых сгенерированы иконки и превью
```

### Иконки (`art/icons/`)

| Группа | Файлы |
|---|---|
| Главные кнопки (слева 2×2) | `btn_shop`, `btn_pets`, `btn_auras`, `btn_rebirth`; колесо фортуны — `btn_wheel` |
| Правый верхний угол (без фона, под колесом) | `bar_achievements`, `bar_rewards`, `bar_daily` (ежедневные задания), `bar_settings`. Есть и `bar_carts` (вагонетки), но кнопка убрана из интерфейса |
| Прочие кнопки | `btn_inventory`, `btn_levels`, `btn_lobby`, `btn_back`, `btn_trade`, `btn_close`, `btn_lock`, `btn_donate` |
| Показатели | `stat_strength` (золотая кирка), `stat_luck` (клевер), `stat_wins` (кубок) |

**Анимация.** Для анимированных кнопок есть отдельные слои: `layer_tile_*` (фон-плитка) и `layer_sym_*` (символ поверх). У колеса это `layer_wheel_base`, `layer_wheel_disc` (вращается) и `layer_wheel_top`. В игре символы анимирует TweenService:
- магазин покачивается;
- лапка подпрыгивает;
- пламя аур пульсирует и светится;
- стрелки перерождения крутятся;
- по плиткам пробегает блик;
- колесо вращается, «!» пульсирует;
- нижние кнопки покачиваются, шестерёнка крутится, подарок трясётся.

Пример — ролик `art/preview/hud_animation.mp4`.

Подписи («Магазин», «Питомцы»…) на картинки **не впечатаны**. В игре это будут отдельные TextLabel, поэтому текст, размер и цвет подписей можно менять в Studio без перерисовки иконок.
| Геймпассы | `pass_wins_x3`, `pass_strength_x2`, `pass_luck_x2`, `pass_auto_click` |
| Кирки (12 шт.) | `pick_01_wood` … `pick_12_rainbow` |
| Руды | `ore_coal`, `ore_iron`, `ore_gold`, `ore_emerald`, `ore_ruby` |
| Яйца | `egg_common`, `egg_rare`, `egg_epic`, `egg_legendary` |

**Как они попадут в игру.** Когда у вас будет Studio, откройте **View → Asset Manager → Bulk Import** и выберите все PNG из `art/icons/`. Roblox выдаст каждой картинке ID вида `rbxassetid://123…`. Эти ID мы впишем в один конфиг `IconConfig`, и кнопки возьмут их оттуда. Изображения проходят модерацию Roblox, обычно она занимает несколько минут.

### 3D-превью (`art/preview/`)

Это **не Roblox**, а макет в браузере (three.js), собранный по вашему ТЗ, чтобы вы могли заранее проверить планировку:

- вход в уровни стоит на центральной оси. Это арка **без портала**: через неё сразу виден коридор и первая стена. Яйца напротив входа;
- магазин кирок справа сделан **ступенями в 3 ряда**: ряд 1 на полу, ряды 2 и 3 каждый на ступеньку выше, посередине лестница. Перед каждой киркой площадка с ценой в победах: встал на неё — купил;
- ямы прокачки стоят слева **двумя рядами по 6, лицом друг к другу**. Между рядами широкая дорожка, между ямами поперечные проходы, вход в забор смотрит на дорожку, таблички стоят с дальней стороны ямы и развёрнуты к главному проходу. Каждая яма окрашена в свой материал: стенки, бортик и кристаллы. Открыта Землянка; Угольная, Каменная, Железная, Золотая и Алмазная закрыты до нужного числа перерождений; 6 мест свободны под новые ямы;
- торговец в углу, центральный проход свободный;
- 10 уровней идут по прямой, в каждом по 10 слоёв;
- между уровнями ниша с наградой (+1 / +3 победы) и кнопкой «В лобби».

В Roblox Studio карта будет собрана из обычных Part и Model с такими же размерами и расположением. Всё можно будет двигать инструментами Move, Scale и Rotate.

## Как пересобрать (для разработчика)

Файл игры: `python3 tools/build_place.py` (берёт скрипты из `src/`).

Иконки и превью:

```bash
npm i three@0.160.0 @fontsource/russo-one@5.0.18      # в любой папке
node tools/render-icons.mjs   <путь к node_modules>
node tools/render-preview.mjs <путь к node_modules> all 24
```
